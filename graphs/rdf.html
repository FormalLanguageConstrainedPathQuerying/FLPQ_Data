Canonical grammars#

Nested parentheses grammars introduced in “Context-Free Path Queries on RDF Graphs”. Template for these grammars is described on the Nested Parentheses page.

\[\begin{split}S \, \rightarrow \, subClassOf_r \, S \, subClassOf \, \mid \, subClassOf_r \, subClassOf \, \\ S \, \rightarrow \, type_r \, S \, type \, \mid \, type_r \, type \, \\\end{split}\]

Pyformlang CFG:

S -> subClassOf_r S subClassOf | subClassOf_r subClassOf
S -> type_r S type | type_r type
\[\begin{split}S \, \rightarrow \, subClassOf_r \, S \, subClassOf \, \mid \, subClassOf_r \, subClassOf \, \\\end{split}\]

Pyformlang CFG:

S -> subClassOf_r S subClassOf | subClassOf_r subClassOf
\[\begin{split}S \, \rightarrow \, type_r \, S \, type \, \mid \, type_r \, type \, \\\end{split}\]

Pyformlang CFG:

S -> type_r S type | type_r type
\[\begin{split}S \, \rightarrow \, broaderTransitive \, S \, broaderTransitive_r \, \mid \, broaderTransitive \, broaderTransitive_r \, \\\end{split}\]

Pyformlang CFG:

S -> broaderTransitive S broaderTransitive_r | broaderTransitive broaderTransitive_r
