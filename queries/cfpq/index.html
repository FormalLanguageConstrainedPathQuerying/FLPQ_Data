CFPQ#

Release:

6.1.2

Date:

Oct 28, 2026

Context-free path queries (CFPQ) constrain the paths of a labeled graph by a context-free language: a pair \((u, v)\) is reachable if some path from \(u\) to \(v\) is labeled by a string of the language. A query is specified by a grammar template instantiated per graph from its stored labels; one query may carry several representations of the same language (a CFG or an RSM). The graph catalog is shared across all query classes — the “Applicable graphs” list below cross-links the per-graph pages without duplicating them.
