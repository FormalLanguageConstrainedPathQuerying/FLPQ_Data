Reachable Pair Counts#

Release:

6.1.2

Date:

Oct 28, 2026

Reference counts of reachable vertex pairs for every graph x grammar pair in the dataset. A pair \((u, v)\) is reachable if there exists a path from \(u\) to \(v\) labeled by a string in the language of the grammar’s start symbol. The sections below follow the graph categories of the Graphs catalog.

Note

Values marked “not available” have not been computed yet. The count is a property of the graph and grammar only; it does not depend on the algorithm or environment used to compute it.

Download#

The full table is available as a CSV file. It ships with the package (REACHABLE_PAIRS_CSV), so the API works offline, and is republished — versioned — on the dataset object storage at https://cfpq-data.storage.yandexcloud.net/<major>.0.0/reachable_pairs.csv.

  • Package API: from flpq_data.dataset import reachable_pairs, REACHABLE_PAIRS_CSV. flpq_data.dataset.download_reachable_pairs() fetches the versioned copy from the object storage into the local data cache; once downloaded, flpq_data.dataset.reachable_pairs() reads it instead of the bundled table, so a table updated on the storage is used without reinstalling.

  • CSV file: reachable_pairs.csv

Columns: graph, grammar, category, query_class (one of cfpq, rpq, mcfpq — the names of the queries/<class>/ directories in the graph archives), num_reachable_pairs (empty when not yet available).
