graph_to_text(graph: MultiDiGraph, *, quoting: bool = False) → Iterator[str][source]#

Turns a graph into its text representation.

One line per edge; the label is taken from the edge’s label attribute (the same convention as graph_to_mtx_dir).

Parameters:
graphMultiDiGraph

Graph to text.

quotingbool

If true, quotes will be added.

Returns:
textstr

Generator of graph edges.

Examples

>>> from flpq_data import *
>>> g = labeled_cycle_graph(2)
>>> list(graph_to_text(g, quoting=True))
["'0' 'a' '1'", "'1' 'a' '0'"]
>>> list(graph_to_text(g, quoting=False))
['0 a 1', '1 a 0']

iter_edges_from_text(text: Iterable[str]) → Iterator[Tuple[str, str, str]][source]#

Yields the edges of a text representation as a stream.

Each line is FROM LABEL TO — three whitespace-separated tokens; quoting is allowed, as in shell syntax.

Parameters:
textIterable[str]

The lines with which the edges will be created.

Returns:
edgesIterator[Tuple[str, str, str]]

The (u, label, v) edge tuples in line order.

Raises:
ValueError

If a line does not match the FROM LABEL TO format.

Examples

>>> list(iter_edges_from_text(["1 A 2", "'3' 'b_5' '4'"]))
[('1', 'A', '2'), ('3', 'b_5', '4')]
iter_edges_from_txt(path: Path | str) → Iterator[Tuple[str, str, str]][source]#

Yields the edges of a TXT file as a stream.

The file holds one FROM LABEL TO edge per line (see iter_edges_from_text()).

Parameters:
pathUnion[Path, str]

The path to the TXT file with which the edges will be created.

Returns:
edgesIterator[Tuple[str, str, str]]

The (u, label, v) edge tuples in line order.

Examples

>>> import pathlib, tempfile
>>> p = pathlib.Path(tempfile.mkdtemp()) / "g.txt"
>>> _ = p.write_text("1 A 2\n3 b_5 4\n")
>>> list(iter_edges_from_txt(p))
[('1', 'A', '2'), ('3', 'b_5', '4')]
txt_from_edges(edges: Iterable[Tuple[str, str, str]], path: Path | str, *, quoting: bool = False) → Path[source]#

Writes an edge stream to a TXT file.

One FROM LABEL TO line per edge (the format of iter_edges_from_text()); the memory stays O(1) in the number of edges.

Parameters:
edgesIterable[Tuple[str, str, str]]

The (u, label, v) edge tuples to write.

pathUnion[Path, str]

The path to the TXT file where the edges will be saved.

quotingbool

If true, quotes will be added.

Returns:
pathPath

Path to the TXT file where the edges will be saved.

Examples

>>> import pathlib, tempfile
>>> p = pathlib.Path(tempfile.mkdtemp()) / "g.txt"
>>> _ = txt_from_edges([("1", "A", "2")], p)
>>> p.read_text()
'1 A 2\n'
